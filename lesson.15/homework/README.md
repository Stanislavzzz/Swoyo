# Домашнее задание. HTTP-запросы и работа с REST API

## Подключение

Используем бесплатный учебный REST API:

```text
https://dummyjson.com
```

**Регистрация, токен и API-ключ не нужны.**

Для работы достаточно:

```bash
pip install requests
```

Раздел с рецептами:

```text
https://dummyjson.com/recipes
```

DummyJSON позволяет получать и искать рецепты, сортировать данные, а также выполнять тестовые `POST`, `PATCH` и `DELETE`. Изменения не сохраняются в реальной базе — сервер только имитирует операцию и возвращает результат. https://dummyjson.com/docs/recipes

### Важно для POST/PATCH

На занятии использовали:

```python
requests.post(url, data=data)
```

Здесь будем отправлять **JSON**:

```python
response = requests.post(url, json=data)
```

`requests` сам преобразует словарь Python в JSON.

# Задание 4. Добавление рецепта — POST

Отправьте новый рецепт на:

```text
/recipes/add
```

Данные:

```python
{
    "name": "Student Pasta",
    "cuisine": "Italian",
    "prepTimeMinutes": 10,
    "cookTimeMinutes": 15,
    "servings": 2
}
```

Также передайте заголовок:

```text
X-Lesson: 15
```

Выведите:

- метод запроса;
- HTTP-статус;
- отправленный `X-Lesson`;
- ID из ответа;
- название;
- кухню.

### Пример формата

```text
Метод: POST
Статус: <HTTP-статус>
X-Lesson: 15
ID: <новый ID>
Название: Student Pasta
Кухня: Italian
```

DummyJSON вернёт добавленный объект с новым ID, но реально рецепт в базе не сохранится. https://dummyjson.com/docs/recipes
