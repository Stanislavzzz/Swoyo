# Задание 1. Прогноз стоимости квартиры

Постройте модель, которая прогнозирует стоимость квартиры.

Используйте:

- площадь;
- количество комнат

для прогнозирования:

```text
price_rub
```

### Требования

Разделите данные на обучающую и тестовую выборки:

```text
80% — обучение
20% — тест
```

Используйте:

```text
random_state=42
```

Для задачи используйте готовую модель линейной регрессии из `scikit-learn`.

> Подсказка: модель называется `LinearRegression`. Она работает по уже знакомой схеме обучения и получения прогноза.

Обучите модель на обучающей части и получите прогноз для трёх квартир:

```text
45 м², 1 комната
65 м², 2 комнаты
90 м², 3 комнаты
```

Выведите результат в виде таблицы:

```text
area_m2 | rooms | predicted_price
```

Округлите цену до целого числа.

### Контрольный результат

При указанных параметрах разбиения должно получиться примерно:

```text
45 | 1 | 6456874
65 | 2 | 8662711
90 | 3 | 11337147
```

# Задание 2 ⭐. Какая модель прогнозирует лучше?

Проверьте, помогает ли количество комнат улучшить прогноз.

Обучите две модели на одинаковых обучающих и тестовых данных.

### Модель 1

Использует только:

```text
area_m2
```

### Модель 2

Использует:

```text
area_m2
rooms
```

Для обеих моделей:

1. получите прогнозы на тестовой выборке;
2. посчитайте абсолютную ошибку каждого прогноза;
3. найдите среднюю абсолютную ошибку;
4. определите, какая модель работает точнее.

`mean_absolute_error` использовать не обязательно — ошибку можно рассчитать средствами Pandas.

Сформируйте таблицу:

```text
area_m2
rooms
price_rub
prediction_area
prediction_area_rooms
```

Сохраните её:

```text
apartment_predictions.csv
```

Для более точной модели постройте диаграмму рассеяния:

```text
X — реальная цена
Y — предсказанная цена
```

### Контроль

При:

```text
test_size=0.2
random_state=42
```

средняя абсолютная ошибка должна быть примерно:

```text
Только площадь:       155579 руб.
Площадь + комнаты:    119115 руб.
```

То есть в этом наборе данных вторая модель должна показать лучший результат.
