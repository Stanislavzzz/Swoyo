# Домашнее задание. SQL и подключение Python к PostgreSQL

## Подготовка

Для выполнения ДЗ нужен запущенный PostgreSQL.

Можно выбрать один из вариантов:

1. Установить PostgreSQL на компьютер:  
https://www.postgresql.org/download/

2. Использовать Docker Compose, который показан на занятии.

Для Docker-варианта запустите:

```bash
docker compose up -d
```

Проверьте контейнеры:

```bash
docker compose ps
```

Проверьте PostgreSQL:

```bash
docker compose exec postgres pg_isready
```

Если используете Docker Compose, можно работать с базой, указанной в `POSTGRES_DB`.

Если PostgreSQL установлен локально, создайте отдельную базу, например:

```text
warehouse
```

При подключении из Python используйте свои параметры:

```text
host
port
dbname
user
password
```

Если Python запускается на компьютере, а PostgreSQL работает в Docker, обычно используется:

```text
host=localhost
```

и порт PostgreSQL, указанный в `.env`.

> Установка и настройка PostgreSQL отдельно не оцениваются. 
> Основная задача ДЗ - SQL и работа с базой данных из Python через `psycopg`.

# Задание 1. Склад в PostgreSQL

Создайте две связанные таблицы для небольшого склада.

## Категории

Храните:

- идентификатор;
- название категории.

Название категории должно быть обязательным и уникальным.

## Товары

Храните:

- идентификатор;
- название товара;
- категорию;
- цену;
- количество на складе.

### Требования

Категория товара должна быть связана с таблицей категорий.

Цена должна быть больше `0`.

Количество товара не может быть отрицательным.

Самостоятельно добавьте:

- минимум `3` категории;
- минимум `10` товаров.

## SQL-запрос

Получите товары, которые:

- есть в наличии;
- стоят дешевле `30000`.

Выведите:

```text
название товара
категория
цена
количество
```

Отсортируйте товары от самого дорогого к самому дешёвому.

Оставьте первые `5` результатов.

## Python

Создайте Python-скрипт, который:

- подключается к PostgreSQL через `psycopg`;
- выполняет созданный SQL-запрос;
- получает все строки результата;
- выводит их в консоль.

Для подключения и курсора используйте контекстные менеджеры.

### Пример формата

```text
Монитор | electronics | 28000.00 | 3
Кресло | furniture | 18000.00 | 4
```

# Задание 2 ⭐. Отчёт по категориям

Используйте те же таблицы.

Получите из PostgreSQL все товары, которые есть в наличии, вместе с их категориями.

Отсортируйте:

1. по категории;
2. внутри категории - от самого дорогого товара к самому дешёвому.

В Python сформируйте отчёт:

- оставьте не больше `2` самых дорогих товаров каждой категории;
- для каждого товара рассчитайте стоимость остатка:

```text
цена × количество
```

Сохраните результат:

```text
top_products.csv
```

Столбцы:

```text
category,name,price,quantity,stock_value
```

Для SQL-части достаточно команд, которые разбирали на занятии.
