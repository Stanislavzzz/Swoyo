# Задание 1. Структура проекта и HTML-каталог

Переработайте Warehouse API.

## Требования

Разделите проект на отдельные части:

- основной файл приложения;
- Pydantic-схемы;
- API-маршруты;
- HTML-маршруты;
- шаблоны.

Подключите маршруты через `APIRouter`.

Для товара используйте две связанные схемы:

- базовую схему товара;
- схему товара с `pk`, созданную через наследование.

Начальные товары должны иметь уникальные `pk`.

`pk` товара должен оставаться постоянным и не зависеть от позиции в списке.

После удаления товара его `pk` не должен использоваться повторно для нового товара.

Сохраните функциональность из ДЗ 17:

- получение списка товаров;
- получение одного товара;
- создание;
- изменение;
- удаление;
- фильтрацию по категории, цене и наличию;
- обработку HTTP-ошибок.

## HTML-каталог

Добавьте HTML-страницу со списком товаров.

Для каждого товара покажите:

- название;
- категорию;
- цену;
- количество;
- наличие.

Название товара должно вести на отдельную страницу этого товара.

На странице списка также покажите:

- количество отображаемых товаров;
- общую стоимость их остатков.

Добавьте фильтрацию HTML-каталога:

- по категории;
- по наличию.

На отдельной странице товара покажите:

- `pk`;
- название;
- категорию;
- цену;
- количество;
- стоимость всего остатка этого товара.

Если товар не найден, вернуть `404`.

# Задание 2 ⭐. Аналитика склада

Доработайте проект из задания 1.

Добавьте отдельную HTML-страницу статистики склада.

Выведите:

- количество разных товаров;
- общее количество единиц;
- общую стоимость склада;
- количество разных товаров в каждой категории;
- стоимость остатков каждой категории;
- самый дорогой товар;
- товар с самым большим остатком;
- категории, в которых есть товары с нулевым остатком.

Страница должна корректно работать и при пустом складе.

Дополнительно сделайте отдельную HTML-страницу категории.

Для выбранной категории покажите:

- название категории;
- список товаров;
- количество разных товаров;
- общее количество единиц;
- общую стоимость остатков.

Со страницы статистики должна быть возможность перейти на страницу каждой категории.

Если такой категории нет, вернуть `404`.
